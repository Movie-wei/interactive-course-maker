# interactive-course-maker

把「一栏一栏引导共创教学内容」和「单文件闯关式交互 HTML 课程」固化成一套可复用的学习法。

对任意新领域，先通过对话和你共创出真正属于你的内容，再装配成**单文件、离线、带闯关与自检的交互 HTML 课程**，并按验收真实产品的标准验证后才交付。

## 它做什么

- **先共创，后装配**：内容必须由你自己说出来，AI 只负责引导提问和整理，不代填、不甩参考原文。
- **领域事实不乱写**：法规、费率、流程这类事实，要么先查权威来源，要么标注「教学示意，以权威部门为准」。
- **产出单文件 HTML**：无外部引用、无 CDN、可离线打开，数据存在浏览器本地。
- **带题型**：翻卡、SVG 图解、即时测验、排序、找错、情景闯关、自评与可复制的学习报告。
- **真验证**：用无头浏览器真点击跑断言，再逐页量字号、重叠、间距、文字是否超框。

## 安装

这是一个 Agent Skill。把 `interactive-course-maker` 文件夹放进技能目录即可：

```bash
git clone https://github.com/13926829782/interactive-course-maker.git
```

然后把仓库里的 `interactive-course-maker/` 文件夹复制到你的技能目录，例如：

- 用户级：`~/.agents/skills/interactive-course-maker/`
- Windows：`C:\Users\<你>\.agents\skills\interactive-course-maker\`

不同的 AI 编程工具技能目录可能不同，请以你所用工具的文档为准。

## 使用

这个 skill **只在手动点名时触发**，不会自动加载。对话里这样说：

> 用课程制作法学习《XX》领域，目标是我学完能 YY

AI 会按六个阶段推进：

| 阶段 | 名称 | 产出 |
|---|---|---|
| 0 | 摸底与目标 | 领域名、贯穿场景、周计划 |
| A | 内容共创 | 逐栏定稿的学习内容 |
| B | 课程设计 | 章节清单与题型映射 |
| C | 工程化装配 | 单文件 HTML |
| D | 验证 | 断言全过、逐页检查 |
| E | 交付入库 | 文档同步与 git 提交 |


## 验证环境说明

验证脚本模板基于 Chromium 内核浏览器（示例用 Edge）加 `--remote-debugging-port`，配合 Node 24 自带的 `WebSocket` 驱动，不需要安装任何 npm 依赖。路径和浏览器位置请按你的机器调整。

## 视觉规格（摘要）

经过多轮真实反馈沉淀，规格写成了可脚本断言的硬性条款：

- 字号分层：正文 ≥16px，辅助 ≥15px，标题 ≥20px，SVG 内文字 ≥12px。
- 只允许术语、标题、关键词加粗，禁止整段加粗。
- 行高 1.65 到 1.75，卡片内边距 22 到 26px。
- 卡片和 SVG 节点不得重叠、不得越界；SVG 文字宽度要适框，两侧留白 ≥12px，且不加描边。

完整版见 `SKILL.md` 第 6、7 节和 `references/踩坑清单.md`。
