# 交互组件库

> 每个题型一行定位、一段实现要点、一段骨架。装配课程时按 §5 映射选型，直接复用本库要点，禁止重写轮子。
> 对应踩坑编号见 `踩坑清单.md`。

## 通用机制（所有章节共用）

1. **状态 → 渲染**：状态变化统一调用渲染函数重绘，不零散改单个节点（坑 6）。完成/重玩/重置都走这条路。
2. **锁定态可见**：未解锁按钮变灰 + 写明解锁条件（如「还剩 N 关」），点击给提示；不用原生 `disabled` 吞掉点击（坑 4）。
3. **动态元素**：创建即挂载（appendChild），测试断言「可点击元素数量 > 0」（坑 7）。
4. **命名**：状态键与 DOM id 不同后缀（如 `gjScore` 与 `gjScoreTxt`）或集中在配置对象声明，防止互相覆盖（坑 9）。
5. **存储**：localStorage 键 `{领域拼音}Week{N}ProgressV1`，含章节完成、答案、分数；重置带二次确认。
6. **反馈**：每个输入控件必须有提交动作与可见反馈（坑 5）；自检与参考答案要标注「不等于评分」。

## 题型库

### 1. 翻卡（概念记忆）
- 实现：`.flip` 固定高度（如 190px）+ `width:100%`；`.flip-inner/.face` 显式 `display:block`，禁止 span（坑 1）。
- 背面 = **术语首词 17px 加粗近黑 + 解释文字 16px 常规**（禁止整段 17px 加粗）；正面白底，示例白底标签；辅助灰不浅于 `#4f5d73`（坑 2）。
- 骨架：`.flip > .flip-inner(transform:rotateY) > .face.front/.face.back`
  - `.back` 内：`<div class="def-term">术语</div><div class="def-body">解释（常规字重）</div>`

### 2. 内联 SVG 图解（结构/关系理解）
- 一律内联 SVG，禁止绝对定位 div + 旋转线拼图（坑 3）。
- 带箭头 `marker-end`、`viewBox` 等比缩放、`role="img"` 加文字描述。节点文字 `stroke="none"`，禁止白描边（白字落在深底上会糊成一团）。

### 3. 即时测验 MCQ（判断/辨析）
- 提交后逐题显示解析，满分 100；未答完拒绝提交并提示。
- 抽通用函数 `mcq({container, questions, onDone})`，一处修处处生效（坑 10）。
- 故意答错也要有反馈路径（不改分、提示正确选项与解析）。

### 4. 排序题（流程/优先级）
- 上移/下移按钮实现；不做真随机（用固定轮换，避免「最好总在第一个」）。
- 提交时按相对顺序判定，说明判定口径（如「不完全一致但相对顺序正确也可」）。

### 5. 找错题（陷阱识别）
- 一个错误对应多行时，按**错误分组**判定命中、显示与计分三处口径一致（坑 8）：选中该错误任一行 → 该错误所有行都标记已找到。
- 支持重做（先误选再重做不改最终分）；固定一段样本用熟后可加多套变体。

### 6. 情景闯关（场景演练）
- 选项即时反馈 + 右侧事实面板同步；通关给解锁条件，支持重玩；通关后重新渲染界面（坑 6）。

### 7. 模拟对话（与人打交道）
- 分支对话，每轮选项乱序由固定轮换规则打乱（不是真随机）；记录进度到 localStorage；选满轮数后收尾。

### 8. 开放题（表达）
- 模板 + 参考答案；自检只做结构检查（关键词、必填、字数阈值），如实标注「自检不等于评分」。
- 阈值一处声明（如 `const MIN_CHARS = 450`），测试断言与页面口径一致；显示当前字数。

### 9. 汇报稿（面向讲清楚）
- 字数自检 + 关键词检查；阈值按课程定（如 450 字）；标注「不评分」。
- 页面给「不看稿讲解」的练习指引（HTML 只能练结构，真实汇报需人当面进行，页面明说）。

### 10. 自评（综合评估）
- 不预填分数；必须配证据清单；权重计算（如 50/60/70/80/60/40）；>100 拒绝；证据不足一半而自评高时提示「可能高估」。
- 显著标注「自评分不是正式成绩」。

## 报告页（每份课程末尾）

- 可复制学习摘要：章节完成数、各题得分、开放题答案、自评结果；格式全课程一致，供对话批改。
- 章节数等写死数字与首页、报告页保持一致（增删章节必须同步）。

## 视觉规格速查

- 背景 `#f5f7fb`，卡片白，主色 `#496fe6`，辅助薄荷 `#26a789`，提醒琥珀 `#d68a24`；
- 布局：左导航 + 主区单列 `minmax(0,1fr)`，卡片圆角 22px；窄屏导航横向滚动；
- 动画：淡入 + 翻卡；支持 `prefers-reduced-motion`。

### 字号分层（硬性，禁止越级）

| 层 | 最小字号 | 字重 | 用途 |
|---|---|---|---|
| 课程标题 h1 | 26px | 700 | 首页课程名 |
| 章节标题 h2 | 22px | 700 | 章节页标题 |
| 小节标题 h3 | 20px | 600 | 章内小节 |
| 术语/定义首词 | 17px | 700 近黑 | 翻卡背面首词、关键定义 |
| 正文/题干/选项/解释 | 16px | 400 | 一切可读正文 |
| 辅助文字（muted/标签/导航/提示） | 15px | 400，颜色 ≥ `#4f5d73` | 说明性弱信息 |
| SVG 节点标题 | 14px | 600 | 图解方框内标题 |
| SVG 辅助说明 | 12px | 400 | 图解方框内小字 |

**加粗边界**：同一卡片内只允许首词/标题/关键词加粗；解释性正文一律常规字重。**禁止整段加粗**——翻卡背面、解析文字、事实面板都是「术语加粗 + 正文常规」结构。

### 间距规范（硬性）

- 行高：1.65~1.75；
- 卡片内边距：22~26px；卡片间距：14~18px；
- 段落间距：10~14px；标题上下留白 ≥8px；列表项间距 ≥6px；
- 相邻卡片垂直间距 ≥12px（脚本可断言）。

### SVG 节点约束（硬性）

- 每个节点矩形 `x≥0 && y≥0 && x+w ≤ viewBox宽 && y+h ≤ viewBox高`；
- 任意两节点矩形不相交（两两检查）；
- 文字用 `<text>`，`stroke="none"`、`pointer-events:none`（点击落到节点矩形），字号按上表分层；副标题字数 ≤ `(框宽-24)/字号`（280 宽、13px ≈ 19 字），超了缩写，细节放点击后的解释；
- 连线带箭头 `marker-end`；`role="img"` 加文字描述。

### 重叠与布局检查（脚本必做）

- 每页所有可见卡片/方框 `getBoundingClientRect` 两两不相交（忽略嵌套包含）；
- 窄屏 512/390 两档 `scrollWidth ≤ innerWidth`；
- 动态生成的方框同样检查。
