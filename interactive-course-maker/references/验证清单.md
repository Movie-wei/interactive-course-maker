# 验证清单（出厂前逐条打勾）

> 每份课程交付前必须全过；任何一条不过就修，不许带着已知失败交付。
> 历史教训出处：`踩坑清单.md` §二。

## 一、静态检查

- [ ] `node --check` 语法通过（装配后、修改后各一次）
- [ ] 无外部引用：搜索 `http://`、`https://` 零命中（无 CDN、无远程字体、无外图）
- [ ] 写死的章节数/统计与首页、报告页一致（增删章节必须同步三处）

## 二、交互验证（脚本真点，见 `验证脚本模板.js`）

- [ ] 每章至少一次真点击：导航、选项、提交、重玩、重置
- [ ] 故意答错一题：分数不变，提示与解析可见
- [ ] 锁定态按钮：看得出来 + 点击有提示（不受原生 disabled 吞掉）
- [ ] 未答完/未填必填提交被拒绝并提示
- [ ] 刷新恢复：localStorage 预置在页面脚本之前写入（`Page.addScriptToEvaluateOnNewDocument`），单独验证成功
- [ ] 用**用户真实答案**测自检逻辑（不只测编造的好答案）
- [ ] 断言「可点击元素数量 > 0」，防止动态元素创建未挂载

## 三、视觉验证

- [ ] **逐页截图 + 目视检查，禁止只看首页**（历史事故：错乱发生在第 2 页）
- [ ] 512px 与 390px 两档视口：`scrollWidth ≤ innerWidth`（脚本量，不靠猜；无头最小视口约 512px）
- [ ] 截图前等淡入动画 ≥400ms，否则画面发灰
- [ ] 翻卡背面、关系图、代码块等重点页逐张看过
- [ ] **字号断言（脚本）**：正文 ≥16px、辅助 ≥15px、标题 ≥20px、SVG 内文字 ≥12px（遍历 `getComputedStyle` 与 SVG `<text>`）
- [ ] **加粗占比断言（脚本）**：正文段落整段加粗（`<strong>` 或 `font-weight ≥700` 覆盖整段）数量 = 0；只允许术语/标题/关键词加粗
- [ ] **重叠断言（脚本）**：每页可见卡片/方框 `getBoundingClientRect` 两两不相交；SVG 节点矩形两两不相交且全部在 viewBox 内
- [ ] **间距断言（脚本）**：相邻卡片垂直间距 ≥12px；行高 ≥1.6
- [ ] **SVG 文字适框断言（脚本）**：遍历每个 `<text>`，`getBBox()` 宽度与所在节点框比较，两侧留白 ≥12px；桌面宽度与 390px 窄屏各测一次
- [ ] **SVG 文字清晰断言（脚本）**：每个 `<text>` 的 `getComputedStyle().stroke === 'none'`；深底白字节点截图后统计，抗锯齿过渡像素占比 <10%

## 四、内容与免责

- [ ] 领域事实已标「教学示意，正式业务以权威部门为准」或先检索验证
- [ ] 自检类反馈如实标注「不等于评分」
- [ ] 敏感领域（法律/医疗/财务）显著声明「学习材料，不构成专业意见」

- [ ] 临时文件（截图、`.tmp*`、`verify*.js` 副本）全部删除
- [ ] `git status` 干净（无未跟踪临时产物）
- [ ] README、开发说明、进度总账已同步更新
- [ ] 已提交（`feat: 新增{主题}交互课`）
